# Untrained Momentum website

Static, accessible marketing website prepared for Cloudflare Pages.

## Preview locally

Serve this directory with any static file server. There is no build step and the Cloudflare Pages output directory is the repository root.

## Before production cutover

- Connect the contact form to an approved secure form endpoint.
- Confirm public pricing and service-area language.
- Inventory all indexed Wix URLs and complete `_redirects`.
- Add an owned social sharing image and local copies of brand photography.
- Validate structured data and submit `sitemap.xml` in Google Search Console.
- Attach both `untrainedmomentum.com` and `www.untrainedmomentum.com` in Cloudflare Pages.
