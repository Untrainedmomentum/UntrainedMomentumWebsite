Remote Tech Support

Let’s fix it without the house call.

A lot of computer problems do not need an in-home visit. Software, email, accounts, printers, settings and plenty of other issues can usually be handled remotely. I’ve been doing remote support for more than 10 years, so there is very little I can’t at least troubleshoot this way.

Before You Book

Here’s how it works.

$60includes up to 1 hour
  • Chrome Remote Desktop is my preferred option, but you do not have to install it to book. It just gives me the best chance of working directly on the problem.
  • Zoom works too. We can share your screen, use some remote control features, and handle many software installs and troubleshooting tasks that way.
  • Sometimes Windows or Mac will stop remote control for a password, admin approval or security prompt. If that happens, I’ll tell you exactly what to click or enter.
  • You are always in control. You approve access and can end it whenever you want.
  • Please have the computer on, connected to the internet and ready when we start.
  • If we need more than the included hour, additional time is $60/hour.

Optional Remote Access Setup

Want me to be able to work directly on the computer?

You do not have to set this up before you book. If you want the smoothest remote session, Chrome Remote Desktop is usually the best option. If Zoom is enough for the job, we can just use that.

1. Open Chrome Remote Desktop

Open Google’s remote support page on the computer you want help with.

2. Follow the prompts

If Google asks you to install or enable remote support, follow the steps it gives you.

3. Generate a one-time code

At your appointment time, choose Generate Code. It is temporary and only works for that session.

4. Approve the connection

You decide when I connect, and you can disconnect me at any time.
