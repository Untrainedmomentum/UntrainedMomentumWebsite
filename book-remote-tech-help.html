Optional Remote Access Setup

Want me to work directly on the computer?

You do not have to install anything before booking. If you want the smoothest remote session, Chrome Remote Desktop is preferred. Zoom is also available when screen sharing or lighter remote control is enough.

1. Open Chrome Remote Desktop

Go to the Google Chrome Remote Desktop support page on the computer you want help with.

2. Follow the setup prompts

Install or enable the remote support component if Google asks you to.

3. Generate a one-time code

At appointment time, choose Generate Code. The code is temporary and only works for that session.

4. Approve the connection

You decide when access starts and can disconnect me at any time.
